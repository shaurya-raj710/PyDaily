82. Coordinate Deduplicator
A delivery app logs GPS pings as (x, y) integer pairs; the same location can be logged more than once.

Read n coordinate pairs, store each one as a tuple, put them all in a set to drop duplicates, then print the number of unique locations followed by each unique location on its own line, in sorted order.

Input Format
The first line contains an integer n.
The next n lines each contain two integers x y, representing a coordinate pair.
Output Format
Print the number of unique locations on the first line.
Then print each unique x y pair on its own line, in sorted order
